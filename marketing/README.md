# Marketing assets

Visual brand and launch videos for Bridge. Every asset here is generated by
a committed script — nothing hand-tuned is checked in without its generator.

## Layout

| Path | Contents |
|------|----------|
| `logo/` | Brand SVGs (source of truth) + avatar renders |
| `images/` | Social preview, posters, high-res renders |
| `videos/` | Launch videos (MP4) + the intro narration (WAV + transcript) |
| `tools/` | The generators that produce everything above |
| `.build/` | Working dir (git-ignored): frames, captures, scratch |

## The brand

The mark is a **keystone arch**: one arch (the compiler) carries the deck
across six languages; the keystone at the crown is the contract — remove it
and the arch falls. Palette: navy `#0B1026`, teal `#2DD4A8` → indigo `#6380E0`
gradient. Wordmark set in Carlito Bold, converted to paths so every SVG is
self-contained (no font dependency, renders identically everywhere).

| File | Use |
|------|-----|
| `logo/bridge-icon-dark.svg` | Avatar / favicon on dark surfaces (navy tile) |
| `logo/bridge-icon-light.svg` | Avatar / favicon on light surfaces (paper tile) |
| `logo/bridge-lockup-{light,dark}.svg` | README header, docs headers (transparent) |
| `logo/bridge-wordmark-{light,dark}.svg` | Wordmark alone |
| `logo/bridge-icon-512.png`, `bridge-avatar-192.png` | App icon, GitHub avatar |
| `images/bridge-og-image.png` | 1200x630 social preview |

## The videos

| File | Format | Content |
|------|--------|---------|
| `videos/bridge-intro.mp4` | 1920x1080, 34s, narrated | Problem → validate → generate → diff → gate → features |
| `videos/bridge-gate-demo.mp4` | 1920x1080, 18s, silent | The compatibility gate catching a breaking rename |
| `videos/bridge-social-square.mp4` | 1080x1080, 16s, silent | Square cut for social feeds |

Every terminal scene in these videos is **real output**, captured at compose
time by running the CLI in this repo against `examples/` — regenerate and the
transcripts can only change if the product changes.

## Regenerating everything

From a clean clone (Node.js >= 22, Python 3 with `pillow`, `fontTools`,
`cairosvg`, plus ffmpeg on PATH):

```console
$ npm install && npm run build          # builds the CLI the videos capture
$ python3 marketing/tools/generate_logo.py      # SVGs + PNG renders
$ python3 marketing/tools/compose_frames.py     # captures CLI + composes frames
$ python3 marketing/tools/assemble_videos.py    # encodes the three MP4s
```

The narration WAV (`videos/narration-intro.wav`, transcript next to it) is
text-to-speech; regenerate it from `videos/narration-intro.txt` with any TTS
that reads plain text (the committed track was synthesized at speed 1.2, voice
"jam"). `assemble_videos.py` measures the WAV and times the intro to fit it,
so a different narration length does not clip.
